# Swiggy SQL Data Analysis

## Project Overview
This project analyzes Swiggy restaurant data using MySQL to identify
restaurant trends, cuisine popularity, ratings, pricing, and
value-for-money cities.

## Tools Used
- MySQL
- SQL
- MySQL Workbench

## Key Analysis
1. Number of restaurants by city
2. Most popular cuisines
3. Average rating across cities
4. Average cost for two
5. Highest-rated cuisines
6. Highly-rated restaurants with large rating counts
7. Best value-for-money cities

## SQL Concepts Used
- SELECT
- WHERE
- GROUP BY
- ORDER BY
- HAVING
- COUNT()
- AVG()
- CAST()
- ROUND()
- REPLACE()
- REGEXP_REPLACE()
- LIMIT

## Key Business Insights
- Identified cities with the highest restaurant concentration.
- Compared cuisine popularity across locations.
- Analyzed average restaurant ratings.
- Compared average cost across cities.
- Identified potential value-for-money cities.
